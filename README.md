# 💬 URLComments (어디든 남기는 내 의견)

🌎 [English Version](README.en.md)

**URLComments**는 웹상의 모든 URL을 하나의 소통 공간으로 만들어주는 크롬 확장 프로그램입니다. 기사, 블로그, 쇼핑몰 등 URL이 있는 곳이라면 어디서든 사람들과 자유롭게 의견을 나누고 소통해보세요.

## ✨ 주요 기능
- **간편한 소통**: Google 계정으로 1초 만에 로그인하고 바로 댓글을 남길 수 있습니다.
- **실시간 반응**: 현재 보고 있는 페이지(URL)에 대한 다른 사람들의 댓글을 실시간으로 확인하세요.
- **좋아요/싫어요 및 정렬**: 유용한 댓글에 투표하고 최신순, 좋아요순, 싫어요순으로 정렬하여 볼 수 있습니다.
- **사이드 패널 지원**: 웹서핑을 방해하지 않는 깔끔한 사이드 패널 UI를 제공합니다.

## 🛡️ 프라이버시 최우선 (Privacy-First)
URLComments는 사용자의 개인정보와 웹 브라우징 기록을 소중히 생각합니다.
- **백그라운드 추적 금지**: 탭을 이동하거나 웹사이트를 방문할 때마다 사용자의 방문 기록(URL)을 자동으로 서버에 전송하지 않습니다.
- **수동 새로고침**: 사용자가 명시적으로 확장 프로그램 아이콘을 클릭하거나 패널에서 '새로고침'을 누를 때만 해당 페이지의 댓글을 불러옵니다.
- **데이터 최소화**: 서비스 제공에 필수적인 현재 탭의 URL과 인증을 위한 기본 프로필(이메일, 이름)만을 사용합니다.

### 프라이버시 우선 새로고침

URLComments는 사용자가 직접 새로고침을 요청할 때만 현재 페이지 URL을 확인하고 댓글을 불러옵니다. 탭 전환이나 페이지 이동만으로 URL을 자동 전송하거나 백그라운드에서 댓글을 조회하지 않습니다.

자동 새로고침은 향후 검토할 수 있는 기능이지만, 브라우징 프라이버시와 불필요한 요청 비용에 미치는 영향을 고려하여 현재는 제공하지 않습니다.

### 향후 꾸미기 기능

URLComments는 사용자 업로드 이미지보다 운영자가 사전 검수한 안전한 아바타 중심의 꾸미기 기능을 우선 검토합니다. 기본 아바타와 테마형 아바타팩을 향후 제공할 수 있지만, 사용자 임의 프로필 이미지 업로드와 댓글 이미지 첨부는 현재 제공하지 않으며 도입 여부도 확정되지 않았습니다.

자세한 비용 및 운영 관련 제품 정책은 [Future Monetization and Avatars](docs/FUTURE_MONETIZATION_AND_AVATARS.md) 문서를 참고하세요.

## 🚀 설치 및 사용 방법

### 사용자 (일반 설치)
1. **[Chrome 웹 스토어 링크]** (출시 후 링크 예정)에서 확장 프로그램을 설치합니다.
2. 브라우저 우측 상단의 확장 프로그램 아이콘 메뉴에서 💬 URLComments를 고정(Pin)합니다.
3. 의견을 남기고 싶은 웹 페이지에서 아이콘을 클릭하여 사이드 패널을 엽니다.
4. Google 계정으로 로그인 후 자유롭게 댓글을 작성하세요!

### 개발자 (로컬 테스트 및 기여)
1. 이 저장소를 클론(Clone)하거나 다운로드합니다.
2. Chrome 브라우저에서 `chrome://extensions/`에 접속합니다.
3. 우측 상단의 **개발자 모드**를 켭니다.
4. **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭하고 다운로드한 프로젝트 폴더를 선택합니다.

## 🛠️ 기여하기 (Contributor Guide)

URLComments는 오픈소스로, 누구나 자유롭게 기여할 수 있습니다. 버그 제보, 기능 제안, PR(Pull Request)은 언제든 환영합니다!

### 디렉토리 구조
```text
URLComments/
├── manifest.json          # Chrome Extension 설정
├── background.js          # 백그라운드 서비스 워커
├── popup/                 # 사이드 패널 UI 및 비즈니스 로직 모듈 (auth, comments, votes 등)
├── content/               # SPA(Single Page App) 감지 등 콘텐츠 스크립트
├── lib/                   # Supabase 클라이언트 및 환경 변수 설정
├── utils/                 # URL 정규화 등 공통 유틸리티
├── _locales/              # 다국어(i18n) 지원 파일
└── docs/                  # i18n 확장 및 제품 정책(수익화, 아바타) 기획 문서
```

**[다국어(i18n) 지원 확장 계획]**
일본어, 중국어, 스페인어 등 다국어 지원 확장을 위한 i18n 적용 구조 및 fallback 원리에 대한 자세한 내용은 [I18n Expansion Plan](docs/I18N_PLAN.md) 문서를 참고하세요.

### 테스트 환경 구축 및 실행
이 프로젝트는 Jest를 활용하여 단위 테스트를 진행하며, GitHub Actions를 통한 CI가 구축되어 있습니다.
코드를 수정하거나 새로운 기능을 추가할 때는 아래 명령어를 통해 테스트를 통과하는지 확인해 주세요.

```bash
# 의존성 패키지 설치
npm install

# 단위 테스트 실행
npm test
```
